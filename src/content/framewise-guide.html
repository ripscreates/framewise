User guide

How to use Framewise

FFmpeg can do almost anything with video and audio — but its thousand-plus options are a lot to face alone. Framewise turns the common jobs into a friendly, step-by-step guide: you say what you want in plain words, review the exact command it builds, then run it in your browser or copy it for your desktop.

The idea in 30 seconds

Every job in Framewise follows the same three beats. Nothing is hidden, and nothing runs before you've seen exactly what it will do.

1 · Say it in plain words

Type something like "video convert gif" or "shrink this for email". The guide matches your words to a workflow locally in your browser — no AI service, no account, no API key.

2 · Review the command

Each workflow builds a real FFmpeg command, shown live as you adjust options. A plain-language panel explains what every part does, and you can copy the command any time.

3 · Run it your way

Run the conversion right in the browser with the built-in engine, or copy the command and run it in desktop FFmpeg. Your files never leave your device either way.

The walkthrough, step by step

Each workflow shows only the steps it needs. Here is what each one asks, and why.

1 Goal

Tell Framewise what you're after in plain words. It matches keywords locally in your browser — no AI service is contacted.

2 Files

Add files or a whole folder. With batch on, every file gets the same settings and its own output name.

3 Format

MP4 is the safe bet for sharing. WebM is smaller for the web; MOV suits Apple editing apps.

4 Quality

"Balanced" is invisible to most eyes. Go "Smaller" for messaging apps and email.

5 Resize

Vertical and square crop from the centre. Plain resolutions keep the original shape.

6 Trim

Keep the opening, the ending, or a time range. Friendly validation keeps time formats on track.

7 Audio

Evening out volume helps with quiet recordings. Removing audio makes a silent clip.

8 Subtitles

A switchable track is quick and keeps the picture clean. Burn-in is permanent.

9 Output

New files never replace your originals. Choose a folder in Chrome/Edge, or download.

10 Review

Copy the command for desktop FFmpeg, or run it here. Real runs are saved to History.

Not every workflow uses every step. Making a GIF, for example, skips format and quality and goes straight to trimming and sizing. Skip any step you don't need — sensible defaults carry on without you.

Run it your way

When the command looks right, you have two honest options. Both keep your media on your device.

Run in browser

Framewise downloads the FFmpeg engine (about 31 MB, once) and converts your files inside the tab, showing live progress and the engine log. In Chrome and Edge on desktop you can save straight into a folder; other browsers download each finished file.

Copy for desktop FFmpeg

Prefer the terminal, or working with long or 4K video? Copy the exact command and run it in desktop FFmpeg — the browser engine is single-threaded, so big jobs go faster natively.

ffmpeg -i input.mp4 -vf "fps=10,scale=480:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" output.gif
Your runs are remembered. Finished conversions are saved to History with their settings, so you can repeat a job later — just add the files again, since browsers don't let sites keep access to them.

Good to know

Trim first, wait less

Trimming first makes everything after it faster, since less video is processed. For GIFs especially, cut the clip down before anything else.

Your originals are safe

New files never replace your originals. Outputs get their own names, so experimenting is free.

Batch the boring jobs

Drop in a whole folder and every file gets the same settings with its own output name — one setup, many files.

Nothing uploads, ever

Files are read and converted inside the browser tab using FFmpeg compiled to WebAssembly. Only the engine itself is downloaded, from a public CDN, on first use.

Quick answers

The short version of the most common questions.

Do I need to install anything?

Just a current desktop browser. An internet connection is needed once, to download the FFmpeg engine; after that, conversions run locally. Desktop FFmpeg is optional — only if you want to run copied commands in a terminal.

Can Framewise do every FFmpeg task?

The guide covers the common jobs: compress, convert, trim, extract audio, resize, subtitles, and GIFs. FFmpeg itself can do far more — the Help page links the official references for the full toolkit.

Is it slower than desktop FFmpeg?

A little — the browser engine runs single-threaded. For long or 4K videos, copy the command and run it in desktop FFmpeg instead.

Where do my files go?

Nowhere. They stay on your device. In Chrome and Edge on desktop you can save results straight into a folder; other browsers download each finished file.
